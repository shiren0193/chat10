# 聊天10 · 单文件 AI 角色扮演聊天 ＋ iPhone 小手机

一个**纯静态**的 AI 角色扮演（RP）聊天页面，外加一台可以随时打开的「小手机」。

没有后端、没有数据库，所有数据只存在你自己的浏览器里。推到 GitHub Pages 就能用。

- **主聊天**：会话管理 / 字卡人设 / 群聊 / 流式输出 / 手机直连或中转站 / PWA
- **小手机**：iPhone 模拟器（锁屏、密码、iMessage、备忘录、设置…），
  和主聊天**共用一个「脑子」** —— 同一份人设、同一个模型、同一把密钥，两边的剧情互相看得见

---

## 怎么用

1. 打开 `https://<你的用户名>.github.io/chat10/`
2. 手机上：**分享 → 添加到主屏幕**（PWA，全屏、可离线打开界面）
3. 打开 **设置抽屉 → 手机直连 → 开** → 填接口地址（如 `https://www.xinyuntoken.com/v1`）与密钥
4. 点「**测试直连**」通过后即可开始聊；右下角 **📱** 打开小手机

> 密钥只保存在本机浏览器（`localStorage`），不会上传到任何服务器；**导出的备份也不含密钥**。

## 小手机和主聊天怎么联动

| 能力 | 说明 |
| --- | --- |
| **共用脑子** | 小手机不单独填密钥，通过 iframe 向主聊天取「当前会话的人设 + 模型 + 密钥」 |
| **剧情互通** | 小手机最近 10 条 → 主聊天的 system；主聊天最近 14 轮 → 小手机的 system |
| **切换会话 = 换角色** | 主聊天切到哪个会话，小手机立刻变成那个人 |
| **场景信号** | 回复里可用 `📷` `💗` `📍` `🎙` `⏱` 开头的独立一行，渲染成灰底卡片，用来代替动作描写 |
| **编辑 / 重新生成** | 点他发来的气泡即可 |
| **返回** | 左上角常驻「← 主線」；剧情收尾时会弹出「回主線繼續 →」 |
| **他的状态** | 主聊天设置抽屉里设「平静 / 生气 / 离开 / 想她」，小手机解锁时会先开口 |
| **主动来信** | 可选：分开的剧情里由 AI 判定要不要给你发一条 iMessage |
| **密碼挑釁** | 输错锁屏密码会立刻弹一句挑衅（可再让 AI 补一条） |
| **只发消息** | 小手机默认不写动作/旁白（设置面板可关），避免在聊天界面里跑剧情 |

## 部署

推到仓库**根目录**，然后 Settings → Pages → Branch: `main` / `root` 即可。

> ⚠️ 所有文件必须在**根目录**。放到子文件夹里会 404（Pages 只认根目录的 `index.html`）。

---

## 隐私

- 全部数据（会话、人设、小手机聊天记录）存在浏览器 `localStorage`
- 直连模式下，请求由浏览器**直接**发给你填写的中转站 / 服务商，不经过本项目的任何服务器
- 导出的备份**不含 API 密钥**
- 清理缓存或换浏览器会丢数据，重要内容请先导出备份

## 已知问题

- **iOS Safari**：`overflow:hidden` + `border-radius` 在祖先带 `transform` 时不会裁剪，可能导致壁纸溢出手机圆角。
  已加 `-webkit-mask-image` 与 `clip-path` 双保险；若个别机型仍出现，可关闭壁纸的呼吸缩放动画。
- **PWA 缓存**：更新代码后需要**删掉桌面图标再重新添加**，否则可能仍在用旧版本。
- **必须同源**：小手机和主聊天必须在同一个目录/域名下，才能读取彼此的数据。
